    Panatang Makabayan

    Notes

    No AI runs on this site. Everything you see under Inference and Voices was generated once, ahead of time.

    Process

    For each word of the pledge, the text up to that word was given to each model, which wrote the rest. The final word gets nothing: there, the pledge simply ends. Each of the other 62 words has two versions per model: 496 independent calls, none aware of the others. Hovering shows one of the two at random.

    Prompt

    system
You are a helpful assistant.

user
Continue this text from exactly where it stops, even if it stops mid-sentence or mid-line. Output only the continuation.

[the pledge, cut after one of its words]

    Same prompt for every model.* No output language was specified.

    * For the first word, Iniibig, the prompt was slightly varied for one model to elicit a response.

    Models

    ModelMade byOrigin

    Via OpenRouter · temperature 1.0 · max 500 tokens · reasoning off where allowed.

    Reruns

    Some replies were not continuations: a model declined, spoke about the text instead of continuing it, or returned malformed output. These were run again.

    Voices

    The Voices tab is not a prediction. For each voice, Claude Fable 5.1 was given the whole pledge and asked to rewrite it as that person would say it. The language was left for each voice to choose. Each voice has two versions; one is picked at random.

    user
Here is the Panatang Makabayan, the patriotic pledge recited by Filipino schoolchildren:

[the full pledge]

Rewrite it as a Spanish friar in the Philippines in the 1880s would say it: their own pledge, in their own voice, language and worldview. Keep roughly the same length and line structure. Output only the rewritten pledge, no title or commentary.

    Origin

    Originally created for Mga Sigaw ng Bayan Kong Sawi, a prompt of the Santelmo Pambansang Hámon sa Pagtula 2026, which invited poets to answer, with or without AI, the question: who are we, and what is the identity of a Filipino? Selected as one of three winning entries written with AI.

    About the Project

    This project is an experiment in large language model inference. The Panatang Makabayan is cut after each of its words, and four language models are asked to finish it. The hovered word marks the cut; what follows belongs to the machine.

    A second set holds the pledge whole and changes the speaker: ten voices, from a friar of the 1880s to the country itself.

    Every output was generated once, in advance, and is shown as recorded.
